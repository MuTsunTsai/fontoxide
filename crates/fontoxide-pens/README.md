# fontoxide-pens

A Rust port of [`fontTools.pens`](https://fonttools.readthedocs.io/en/latest/pens/):
drawing glyph outlines through pens, and pens that record, transform, filter or
measure them (bounds, area, perimeter, statistics, SVG paths, …). It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::pens` (always included). Depend on
this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_pens::{BoundsPen, Pen};

let mut pen = BoundsPen::new_bounds(None);
pen.move_to((0.0, 0.0))?;
pen.curve_to(&[(0.0, 100.0), (100.0, 100.0), (100.0, 0.0)])?;
pen.close_path()?;
assert_eq!(pen.bounds(), Some([0.0, 0.0, 100.0, 75.0]));
# Ok::<(), fontoxide_pens::Error>(())
```

The pens that build `glyf` glyphs and CFF charstrings are in
[`fontoxide-ttlib`](https://crates.io/crates/fontoxide-ttlib) (`ttlib::pens`).

## Compatibility

This version follows **fontTools 4.68.0**. The pens give the same results as
fontTools', as checked with fontTools' own tests and with fixtures generated by
running fontTools. Differences from fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
