# fontoxide-qu2cu

A Rust port of [`fontTools.qu2cu`](https://fonttools.readthedocs.io/en/latest/qu2cu/):
approximates quadratic splines with cubic Bézier curves, for single splines and
glyphs (through pens). It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::qu2cu` (feature `qu2cu`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_qu2cu::quadratic_to_curves;

let spline = vec![(0.0, 0.0), (0.0, 37.5), (30.2, 75.0), (69.8, 75.0), (100.0, 37.5), (100.0, 0.0)];
let curves = quadratic_to_curves(&[spline], 1.0, false)?;
println!("{curves:?}");
# Ok::<(), fontoxide_qu2cu::Error>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. The arithmetic is the one of
fontTools in pure Python (not compiled with Cython), with Python's complex
numbers, so on the same platform the results are the same as fontTools', bit for
bit, as checked with fontTools' own tests and with fixtures generated by running
fontTools. (The curve fitting amplifies differences in the last digits of the
platform's math library, in fontTools too.) Differences from fontTools are
listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
