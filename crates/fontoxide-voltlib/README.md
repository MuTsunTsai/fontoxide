# fontoxide-voltlib

A Rust port of [`fontTools.voltLib`](https://fonttools.readthedocs.io/en/latest/voltLib/):
reading Microsoft VOLT projects and converting them to feature files. It is part
of [fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to
Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::voltlib` (feature `voltlib`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_voltlib::{Parser, ParserInput};

let doc = Parser::new(ParserInput::text("DEF_GLYPH \"a\" ID 1 END_GLYPH END"))?.parse()?;
assert_eq!(doc.to_string(), "\nDEF_GLYPH \"a\" ID 1 END_GLYPH END\n");
# Ok::<(), fontoxide_voltlib::Error>(())
```

The `volt_to_fea` module converts a project to a feature file, as
`fonttools voltLib.voltToFea` does.

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the output is
the same as fontTools', byte for byte, as checked with fontTools' own tests and
with fixtures generated by running fontTools. Differences from fontTools are
listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
