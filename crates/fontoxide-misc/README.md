# fontoxide-misc

A Rust port of [`fontTools.misc`](https://fonttools.readthedocs.io/en/latest/misc/),
the low-level helpers shared by the other fontoxide crates (fixed-point numbers,
transforms, Bézier tools, plists, XML reading and writing, PostScript, …), and
of the small top-level modules
[`fontTools.agl`](https://fonttools.readthedocs.io/en/latest/agl.html),
[`fontTools.afmLib`](https://fonttools.readthedocs.io/en/latest/afmLib.html) and
[`fontTools.tfmLib`](https://fonttools.readthedocs.io/en/latest/tfmLib.html).
It is part of [fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of
fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::misc`, with `fontoxide::agl`,
`fontoxide::afmlib` and `fontoxide::tfmlib` (always included). Depend on this
crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_misc::agl;

assert_eq!(agl::to_unicode("f_f_i.alt123", false), "ffi");
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the output is
the same as fontTools', byte for byte, as checked with fontTools' own tests and
with fixtures generated by running fontTools. Differences from fontTools are
listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
