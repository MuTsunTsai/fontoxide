# fontoxide-unicodedata

A Rust port of [`fontTools.unicodedata`](https://fonttools.readthedocs.io/en/latest/unicodedata/)
(and `fontTools.unicode`): Unicode character properties (names, scripts, script
extensions, blocks, mirroring, script directions) at the Unicode version
fontTools uses, Unicode 18.0.0. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::unicodedata` (always included).
Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_unicodedata::{name, script, script_name};

assert_eq!(name(0x41).as_deref(), Some("LATIN CAPITAL LETTER A"));
assert_eq!(script('a' as u32), "Latn");
assert_eq!(script_name("Egyp").as_deref(), Some("Egyptian Hieroglyphs"));
```

## Compatibility

This version follows **fontTools 4.68.0** with `unicodedata2` 18.0.0. The data
is exported from fontTools, so the results are the same as fontTools', as checked
with fontTools' own tests and with fixtures generated by running fontTools.
Differences from fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
