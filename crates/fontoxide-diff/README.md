# fontoxide-diff

A Rust port of [`fontTools.diff`](https://github.com/fonttools/fonttools/tree/4.68.0/Lib/fontTools/diff):
compares two fonts table by table, as a unified diff of their TTX dumps, or as a
summary of which tables are present and binary identical. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::diff` (feature `diff`, on by
default). Depend on this crate directly to keep the dependency tree small.

On the command line, this is `fontoxide diff`, from
[`fontoxide-cli`](https://crates.io/crates/fontoxide-cli):

```sh
fontoxide diff old.ttf new.ttf
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same fonts and options, the
output is the same as fontTools', byte for byte, as checked with fontTools' own
tests and with fixtures generated by running fontTools. Differences from fontTools
are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`. The TTX
dumps are made in memory; the pager and external diff tools need an operating
system.
