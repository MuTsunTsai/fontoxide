# fontoxide-cu2qu

A Rust port of [`fontTools.cu2qu`](https://fonttools.readthedocs.io/en/latest/cu2qu/):
approximates cubic Bézier curves with quadratic splines, for single curves,
glyphs (through pens) and whole UFO fonts. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::cu2qu` (feature `cu2qu`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_cu2qu::curve_to_quadratic;

let cubic = [(0.0, 0.0), (0.0, 100.0), (100.0, 100.0), (100.0, 0.0)];
let quadratic = curve_to_quadratic(&cubic, 1.0, true)?;
println!("{quadratic:?}");
# Ok::<(), fontoxide_cu2qu::Error>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. The arithmetic is the one of
fontTools in pure Python (not compiled with Cython), with Python's complex
numbers, so the results are the same as fontTools', bit for bit, as checked with
fontTools' own tests and with fixtures generated by running fontTools.
Differences from fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
