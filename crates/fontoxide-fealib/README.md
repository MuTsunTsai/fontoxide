# fontoxide-fealib

A Rust port of [`fontTools.feaLib`](https://fonttools.readthedocs.io/en/latest/feaLib/):
parsing [OpenType feature files](https://adobe-type-tools.github.io/afdko/OpenTypeFeatureFileSpecification.html)
and compiling them into `GSUB`, `GPOS`, `GDEF` and other tables. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::fealib` (feature `fealib`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_fealib::builder::add_open_type_features_from_string;
use fontoxide_ttlib::{Font, Tag};

let mut font = Font::new();
font.set_glyph_order([".notdef", "f", "i", "f_i"].map(String::from).to_vec());
add_open_type_features_from_string(&mut font, "feature liga { sub f i by f_i; } liga;", None, None, false)?;
assert!(font.contains(Tag::new(b"GSUB")));
# Ok::<(), fontoxide_fealib::Error>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same feature file and font,
the compiled tables are the same as fontTools', byte for byte, as checked with
fontTools' own tests and with fixtures generated by running fontTools.
Differences from fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
