# fontoxide-ufolib

A Rust port of [`fontTools.ufoLib`](https://fonttools.readthedocs.io/en/latest/ufoLib/):
reading and writing [UFO](https://unifiedfontobject.org/) fonts (versions 1, 2
and 3, as directories or `.ufoz` zip files). It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::ufolib` (feature `ufolib`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_pens::RecordingPointPen;
use fontoxide_ufolib::UfoReader;

let reader = UfoReader::new("Font.ufo", true)?;
let glyph_set = reader.get_glyph_set(None, None, None)?;
let mut pen = RecordingPointPen::default();
glyph_set.draw_points("a", &mut pen)?;
let glyph = glyph_set.glyph("a")?; // width, unicodes, anchors, ...
# Ok::<(), Box<dyn std::error::Error>>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the files
written are the same as fontTools', byte for byte, as checked with fontTools' own
tests and with fixtures generated by running fontTools. For `.ufoz`, the files in
the archive are the same, but the zip container bytes are not. Differences from
fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
