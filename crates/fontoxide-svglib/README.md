# fontoxide-svglib

A Rust port of [`fontTools.svgLib`](https://fonttools.readthedocs.io/en/latest/svgLib/):
drawing SVG paths and basic shapes (rectangles, circles, polygons, …) with
pens. It is part of [fontoxide](https://github.com/MuTsunTsai/fontoxide), a port
of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::svglib` (feature `svglib`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_pens::RecordingPen;
use fontoxide_svglib::SvgPath;

let svg = SvgPath::fromstring(
	"<svg xmlns='http://www.w3.org/2000/svg'><rect width='1' height='1'/></svg>",
	None,
)?;
let mut pen = RecordingPen::new();
svg.draw(&mut pen)?;
assert_eq!(pen.value.len(), 6);
# Ok::<(), Box<dyn std::error::Error>>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same SVG, the pens receive
the same calls with the same coordinates as in fontTools, as checked with
fontTools' own tests and with fixtures generated by running fontTools.
Differences from fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
