# fontoxide-colorlib

A Rust port of [`fontTools.colorLib`](https://fonttools.readthedocs.io/en/latest/colorLib/):
building `COLR` (versions 0 and 1) and `CPAL` tables for color fonts, and
unbuilding `COLR` paints back into plain values. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::colorlib` (feature `colorlib`, on
by default). Depend on this crate directly to keep the dependency tree small.

fontTools builds the tables from dicts, tuples and enum names; here such inputs
are `Value`s, written with the `value!` macro. The tables of fontoxide hold glyph
IDs, so the builders also take a glyph name to ID map (`GlyphIds`).

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the tables built
are the same as fontTools', byte for byte, as checked with fontTools' own tests
and with fixtures generated by running fontTools. Differences from fontTools are
listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
