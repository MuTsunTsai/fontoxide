# fontoxide-otllib

A Rust port of [`fontTools.otlLib`](https://fonttools.readthedocs.io/en/latest/otlLib/):
builders for OpenType Layout tables (`GSUB`, `GPOS`, `GDEF` lookups, coverage
and class definitions, …), the `usMaxContext` calculation, and the `GPOS`
compaction of `otlLib.optimize`. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::otllib` (feature `otllib`, on by
default). Depend on this crate directly to keep the dependency tree small.

The `otlLib` options of fontTools' `TTFont.cfg` are fields of
`fontoxide_ttlib::Font`: `gpos_compression_level` and `write_gpos7`.

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the tables built
are the same as fontTools', byte for byte, as checked with fontTools' own tests
and with fixtures generated by running fontTools. Differences from fontTools are
listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
