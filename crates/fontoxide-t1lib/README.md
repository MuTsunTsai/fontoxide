# fontoxide-t1lib

A Rust port of [`fontTools.t1Lib`](https://fonttools.readthedocs.io/en/latest/t1Lib.html):
reading and writing PostScript Type 1 fonts (PFA, PFB and Mac LWFN), parsing
their font programs and drawing their glyphs. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::t1lib` (feature `t1lib`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_t1lib::T1Font;

let mut font = T1Font::open("Font.pfb", "ascii", None)?;
font.parse()?;
font.save_as("Font.pfa", "OTHER", true)?;
# Ok::<(), Box<dyn std::error::Error>>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the output is
the same as fontTools', byte for byte, as checked with fontTools' own tests and
with fixtures generated by running fontTools. Differences from fontTools are
listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
