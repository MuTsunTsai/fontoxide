# fontoxide-designspacelib

A Rust port of [`fontTools.designspaceLib`](https://fonttools.readthedocs.io/en/latest/designspaceLib/):
reading, editing and writing `.designspace` documents, which describe the axes,
sources and instances of a variable font family, and splitting them into
interpolable sub-spaces. It is part of
[fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::designspacelib` (feature
`designspacelib`, on by default). Depend on this crate directly to keep the
dependency tree small.

## Example

```rust,no_run
use fontoxide_designspacelib::DesignSpaceDocument;

let mut doc = DesignSpaceDocument::from_file("MyFont.designspace")?;
println!("{} axes, {} sources", doc.axes.len(), doc.sources.len());
doc.write("MyFont-copy.designspace")?;
# Ok::<(), Box<dyn std::error::Error>>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same input, the documents
written are the same as fontTools', byte for byte, as checked with fontTools' own
tests and with fixtures generated by running fontTools. Differences from fontTools
are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
