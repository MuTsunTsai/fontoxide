# fontoxide-mtilib

A Rust port of [`fontTools.mtiLib`](https://fonttools.readthedocs.io/en/latest/mtiLib.html):
building OpenType Layout tables (`GSUB`, `GPOS`, `GDEF`) and `cmap` from
Monotype/FontDame
[layout source files](http://monotype.github.io/OpenType_Table_Source/otl_source.html).
It is part of [fontoxide](https://github.com/MuTsunTsai/fontoxide), a port of
fontTools to Rust.

Most projects should depend on the [`fontoxide`](https://crates.io/crates/fontoxide)
crate, which re-exports this one as `fontoxide::mtilib` (feature `mtilib`, on by
default). Depend on this crate directly to keep the dependency tree small.

## Example

```rust,no_run
use fontoxide_ttlib::{Font, ReadOptions};

let mut font = Font::read(std::fs::read("font.ttf")?, ReadOptions::default())?;
let source = std::fs::read_to_string("GSUB.txt")?;
let gsub = fontoxide_mtilib::build(&source, &mut font, Some("GSUB"))?;
# Ok::<(), Box<dyn std::error::Error>>(())
```

## Compatibility

This version follows **fontTools 4.68.0**. Given the same source and font, the
tables built are the same as fontTools', byte for byte, as checked with
fontTools' own tests and with fixtures generated by running fontTools.
Differences from fontTools are listed in
[COMPATIBILITY.md](https://github.com/MuTsunTsai/fontoxide/blob/main/COMPATIBILITY.md).

The crate is pure safe Rust and builds for `wasm32-unknown-unknown`.
